# 🛒 বাজার দর | BazarDor

বাজার দর (BazarDor) হলো বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের বাজারদর দেখার একটি ওয়েব অ্যাপ্লিকেশন। এই অ্যাপের মাধ্যমে ব্যবহারকারীরা চাল, ডাল, তেল, সবজি, মাছ, মাংসসহ বিভিন্ন পণ্যের দাম দেখতে এবং বিভিন্ন বাজারের দামের তথ্য জানতে পারবেন।

## ✨ Key Features

1. **Product Categories:** চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম ও দুধ এবং মসলার মতো বিভিন্ন ক্যাটাগরিতে পণ্য দেখা যায়।

2. **Product Price Information:** পণ্যের বর্তমান দাম, একক এবং বাজারভিত্তিক মূল্যসংক্রান্ত তথ্য দেখা যায়।

3. **Price Sorting:** পণ্যের দাম ডিফল্ট, কম থেকে বেশি এবং বেশি থেকে কম ক্রমে সাজানো যায়।

4. **User Authentication:** Better Auth ব্যবহার করে ইমেইল ও পাসওয়ার্ড দিয়ে Sign Up এবং Sign In করা যায়। Google Login-ও সমর্থিত, যদি OAuth configuration করা থাকে।

5. **Protected Product Details:** লগইন করা ব্যবহারকারীরা সুরক্ষিত Product Details পেজ দেখতে পারেন।

6. **Profile Update:** ব্যবহারকারীরা নিজেদের প্রোফাইলের নাম পরিবর্তন করতে পারবেন।

7. **Responsive Design:** মোবাইল, ট্যাবলেট ও ডেস্কটপে ব্যবহার করার উপযোগী ডিজাইন।

8. **Loading and Error States:** ডেটা লোড হওয়ার সময় loading UI এবং প্রয়োজন অনুযায়ী error message দেখানো হয়।
